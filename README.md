# eCommerx — Order Management System

> **eCommerx** is a multi-tenant SaaS Order Management System (OMS) built for e-commerce businesses in the MENA region.

## 🎨 Brand Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| كحلي داكن (Dark Navy) | `#0F172A` | Primary dark color — professional, calming, conveys trust and stability for accounting & management UIs |
| أزرق نيلي / إنديجو (Indigo) | `#6366F1` | Accent color — technology & integrations, modern and distinctive without being flashy |
| رمادي فاتح (Light Gray) | `#F8FAFC` | Background — very soft, easy on the eyes for dashboard and system backgrounds |

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Database**: Supabase (PostgreSQL)
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI + shadcn/ui
- **Charts**: Recharts
- **Animations**: Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
